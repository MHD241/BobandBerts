
# Bob & Berts Website Redesign

A modern, responsive website redesign concept for Bob & Berts, built with HTML, CSS and JavaScript.

## Features

- Responsive desktop and mobile layouts
- Mobile navigation menu
- Animated scrolling text banner
- Coffee shop themed colours and typography
- Menu category cards linking to the official menu
- Featured Dunfermline location with a search field
- Official click-and-collect link
- Gift cards, careers, allergen information and feedback links
- Accessibility features and reduced-motion support
- Automatically updated footer year

## Project files

- `index.html` — website content and page structure
- `styles.css` — layout, colours, animations and responsive design
- `script.js` — interactive features

## Run locally

Download or clone this repository and open `index.html` in a web browser.

An internet connection is needed for the external fonts and café photographs.

## Publish using GitHub Pages

1. Create a new repository on GitHub.
2. Upload all four project files to the repository's main folder.
3. Open the repository's **Settings**.
4. Select **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select your main branch and the `/ (root)` folder.
7. Click **Save** and wait for the site to publish.
8. Open the website URL displayed in the Pages settings.
